# Upstream sources

This repository stores our own setup code, workflows, and skills. Runtime packages and model weights are installed from their sources rather than vendored here.

- [ComfyUI source and license](https://github.com/Comfy-Org/ComfyUI)
- [Comfy MCP source and license](https://github.com/Comfy-Org/comfy-mcp)
- [comfy-cli source](https://github.com/Comfy-Org/comfy-cli)
- [uv source and release artifacts](https://github.com/astral-sh/uv)
- Model-specific sources and exact revisions: [models.lock.json](../Config/models.lock.json)
- `unity-ui-assets` and `blender-props` originated in [AI-UnityPipeline](https://github.com/SinlessDevil/AI-UnityPipeline); they are now maintained only in this repository

The Windows package snapshots describe the source environment's versions. Model/component licenses and supported hardware can differ; consult the pinned source model cards for a new deployment or redistribution.
